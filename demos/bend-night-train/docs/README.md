# Documentation

Research output of the project. The English files at `docs/<name>.md` are the
primary copies.

| Document | What it is |
|---|---|
| `structure.md` | how the renderer is put together: the modules and one frame's path |
| `running.md` | commands, environment variables, the live view, the comparison tools |
| `benchmarks.md` | benchmark numbers and their analysis |
| `laws.md` | what is provable in Bend 2, what is not, and why |
| `journal.md` | chronology of the work: what broke and how it was fixed |
| `language-notes.md` | verified Bend 2 language reference |
| `reference-demo-spec.md` | what the original WebGL demo does, down to the constants |
| `base-2.0.5.txt` | dump of `bend base` for 2.0.5 — the API reference |

The Russian copies of the documents that have one live under `ru/` (for
example `ru/laws.md`, `ru/journal.md`). The project overview is `README.md` at
the repository root; its Russian copy is `README.ru.md`.
