# Документация

Исследовательский вывод проекта. Английские файлы `docs/<имя>.md` — первичные
копии.

| Документ | Что это |
|---|---|
| `structure.md` | как устроен рендерер: модули и путь одного кадра |
| `running.md` | команды, переменные окружения, живой просмотр, инструменты сравнения |
| `benchmarks.md` | числа бенчмарков и их разбор |
| `laws.md` | что в Bend 2 доказуемо, что нет и почему |
| `journal.md` | хронология: что сломалось и как починили |
| `language-notes.md` | проверенный справочник по языку Bend 2 |
| `reference-demo-spec.md` | что делает оригинальная WebGL-демка, до констант |
| `base-2.0.5.txt` | дамп `bend base` для 2.0.5 — справочник по API |

Английские копии документов, у которых они есть, лежат в `docs/<имя>.md` (и
они первичны); русские переводы — здесь, в `docs/ru/`. Обзор проекта —
`README.ru.md` в корне репозитория, его английская копия — `README.md`.
